# PorsiPal asset record

PorsiPal is PorsiPas's first mascot: a friendly mint-green meteor with a leaf sprout and a purple trail. The character supports the product's meteorite FoodDrop theme without imitating or referencing an existing commercial character.

## Files

| File | Intended use | Size |
|---|---|---:|
| `porsipal-neutral.png` | Empty, error, permission, and onboarding moments | 843,405 bytes |
| `porsipal-success.png` | Confirmed rescue celebration only | 856,049 bytes |

Both files are 1536 × 1536 transparent PNGs. The app should display them at a much smaller size and preserve their aspect ratio.

## Generation record

- Created specifically for PorsiPas on 2026-08-30 with OpenAI's built-in ImageGen tool.
- No external reference image or third-party character asset was supplied.
- Generation brief: an original cute round meteor mascot; mint-green cratered body; dark green outline; two-leaf sprout; purple comet trail; peach cheeks; warm expressive face; polished mobile-game sticker illustration; transparent background; no words, logos, watermark, or border.
- The success variant keeps the same character and palette with raised arms, closed happy eyes, and a few small celebratory sparkles.
- Use of generated output remains subject to the applicable OpenAI terms. No separate third-party stock-asset licence is required for these two files.

## Accessibility

The character is decorative unless a screen depends on its pose to communicate meaning. The `PorsiPal` component supplies a short accessible label, but the screen must still state the result in text. Never use the mascot alone to indicate success, failure, or status.
